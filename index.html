📚 Обучение

🏷️ Что такое ТЕГ?

Команда браузеру в угловых скобках.

<h1>Заголовок</h1> <p>Текст</p> <button>Кнопка</button>

Большинство тегов имеют открывающую и закрывающую часть.

⚙️ Атрибуты тегов

Дополнительная информация внутри тега (как настройки):

<a href="https://..."> Ссылка </a>
  • href — адрес ссылки
  • src — путь к картинке
  • alt — описание

📄 HEAD и BODY

Каждый HTML-документ делится на две части:

  • <head> — служебная часть (НЕ видно на странице): CSS, кодировка, заголовок вкладки
  • <body> — всё, что вы видите на странице
head = кухня ресторана (вы не видите)
body = зал ресторана (всё что видите)

📏 Заголовки h1-h6

h1 — самый большой
h2 — поменьше
h3 — ещё меньше
h6 — самый маленький
Запомните: Чем МЕНЬШЕ число — тем БОЛЬШЕ заголовок! h1 = главный, h6 = наименьший

🔗 Ссылки <a>

Тег <a> (anchor — якорь) создаёт кликабельные ссылки:

<a href="https://google.com"> Перейти в Google </a>

href указывает адрес, куда перейти при клике.

🖼️ Картинки <img>

Тег <img> добавляет картинки (не имеет закрывающего тега):

<img src="foto.jpg" alt="Описание">
  • src — путь к файлу картинки
  • alt — описание (если не загрузится)

🎨 CSS: Цвета

Основные свойства для работы с цветом:

color: red; /* цвет текста */ background: blue; /* цвет фона */

Можно использовать названия цветов (red, blue) или коды: #ff0000

📐 CSS: Отступы

  • margin — внешний отступ (снаружи элемента, между элементами)
  • padding — внутренний отступ (внутри элемента, между содержимым и границей)
margin = место МЕЖДУ элементами
padding = место ВНУТРИ рамки

📏 CSS: Размеры

width: 200px; /* ширина */ height: 100px; /* высота */ font-size: 16px; /* размер текста */

width = ширина, height = высота, font-size = размер шрифта

⚡ JavaScript: Введение

Язык программирования для веба:

  • Делает страницы интерактивными
  • Реагирует на клики мыши
  • Может менять содержимое страницы
  • Добавляет анимации

💾 Переменные

Хранение данных (как коробки с подписями):

let name = "Анна"; let age = 25;

let — объявление переменной (создание "коробки")

📊 Массивы

Список данных (как список покупок):

let fruits = ["яблоко", "банан"];
  • push() — добавить элемент в конец
  • pop() — удалить последний элемент
