Как создаётся сайт: история

🎮 Начнём игру!

Представьте: вы хотите построить дом. Но это не просто дом — это веб-сайт!

🏗️ → 💻
Цель: Построить красивый дом (сайт), который будут видеть люди в интернете.

📐 Шаг 1: Чертёж (HTML)

Сначала нужен план дома — где стены, где окна, где двери.

📋
Чертёж
+
🧱
Стены

HTML — это чертёж и каркас сайта. Он говорит: "здесь будет заголовок, здесь текст, здесь кнопка".

🎨 Шаг 2: Отделка (CSS)

Каркас готов! Теперь нужно покрасить стены, постелить пол, повесить шторы.

🏠
Без отделки
→
🏡
С отделкой

CSS — это краски и обои. Он делает сайт красивым: добавляет цвета, шрифты, отступы.

⚡ Шаг 3: Коммуникации (JS)

Дом почти готов! Осталось провести электричество и воду, чтобы всё работало.

💡 + 🚰 + 🔔

JavaScript — это электричество. Он делает дом (сайт) живым: свет включается по кнопке, домофон звонит, вода течёт.

🏗️ Строим вместе!

Теперь соберём всё вместе:

CSS
JS
HTML = каркас (невидимый)
CSS = стены с отделкой
JS = электричество внутри

🔍 Как это видит браузер?

Браузер (Chrome, Firefox) — это прораб, который читает ваши инструкции:

1. Читает HTML → строит каркас
2. Читает CSS → красит стены
3. Читает JS → подключает свет

И показывает готовый дом (сайт) посетителям!

📦 Что такое тег?

Тег — это кирпичик в строительстве. Каждый тег — это команда:

<h1>
Заголовок
<p>
Абзац
<button>
Кнопка
<img>
Картинка

🧩 Собираем страницу

Как конструктор LEGO — соединяем теги:

<h1>Мой сайт</h1> <p>Привет!</p> <button>Нажми</button>
Мой сайт
Привет!

✨ Магия происходит!

Когда вы открываете сайт в браузере:

📄 → 💻 → 🌐
Файл → Браузер → Готовый сайт!
Браузер превращает код (теги) в красивую страницу, которую вы видите!

📚 Обучение

🏷️ Что такое ТЕГ?

Команда браузеру в угловых скобках.

<h1>Заголовок</h1> <p>Текст</p> <button>Кнопка</button>

Большинство тегов имеют открывающую и закрывающую часть.

⚙️ Атрибуты тегов

Дополнительная информация внутри тега:

<a href="https://..."> Ссылка </a>
  • href — адрес ссылки
  • src — путь к картинке
  • alt — описание

📄 HEAD и BODY

<head> — служебная часть:

  • Подключение CSS
  • Кодировка
  • Заголовок вкладки
  • НЕ видно на странице!

<body> — всё, что вы видите

📏 Заголовки h1-h6

h1 — самый большой
h2 — поменьше
h3 — ещё меньше
h6 — самый маленький
Запомните: Чем МЕНЬШЕ число — тем БОЛЬШЕ заголовок!

🔗 Ссылки <a>

Тег <a> (anchor — якорь):

<a href="https://google.com"> Перейти в Google </a>

href указывает адрес, куда перейти.

🖼️ Картинки <img>

Тег <img> (не имеет закрывающего):

<img src="foto.jpg" alt="Описание">
  • src — путь к файлу
  • alt — описание

📝 Абзацы <p>

<p>Это абзац текста.</p> <p>Второй абзац.</p>

<p> (paragraph) создаёт абзац с отступами.

🔲 Контейнер <div>

<div> — универсальный блок:

<div> Здесь может быть что угодно </div>

Используется для группировки элементов.

Списки <ul> и <ol>

<ul> <li>Пункт 1</li> <li>Пункт 2</li> </ul>

<ul> — маркированный список
<ol> — нумерованный

🎨 CSS: Цвета

Основные свойства:

color: red; background: blue;

Можно использовать названия или коды: #ff0000

📐 CSS: Отступы

  • margin — внешний отступ
  • padding — внутренний отступ
margin = снаружи элемента
padding = внутри элемента

📏 CSS: Размеры

width: 200px; height: 100px; font-size: 16px;

width = ширина, height = высота

🔤 CSS: Шрифты

font-family: Arial; font-size: 16px; font-weight: bold;

family = шрифт, weight = жирность

⚡ JavaScript: Введение

Язык программирования для веба:

  • Делает страницы интерактивными
  • Реагирует на клики
  • Может менять содержимое

🖱️ События JS

Реакция на действия:

  • click — клик мышью
  • mouseover — наведение
  • keydown — клавиша

💾 Переменные

Хранение данных:

let name = "Анна"; let age = 25;

let — объявление переменной

📊 Массивы

Список данных:

let fruits = ["яблоко", "банан"];
  • push() — добавить
  • pop() — удалить

🔍 Как браузер читает

  1. Открывает файл
  2. Читает сверху вниз
  3. Видит тег → понимает
  4. Показывает на экране

💡 Советы

  • Не запоминайте всё наизусть
  • Практикуйтесь
  • Используйте F12
  • Не бойтесь ошибаться!

🚀 Первый сайт

1. Создайте index.html

2. Напишите:

<h1>Привет!</h1> <p>Мой сайт!</p>

3. Откройте в браузере — готово! 🎉
